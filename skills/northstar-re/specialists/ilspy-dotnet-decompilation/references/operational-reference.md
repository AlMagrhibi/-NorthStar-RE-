# Managed operational reference
Use tool catalog for ILSpy GUI/CLI, optional ILDasm, compatible .NET. Confirm CLI version and help; parse known synthetic class library first. Inspect assembly identity, target framework, references, TypeDef/MethodDef, IL, resources, P/Invoke, async state machines and generated types. Corroborate C# against IL and metadata; do not assume missing names or comments can be recovered. NativeAOT is not IL; mixed mode requires native analysis too. Exported source is untrusted and must not be built or run without review. Check dependencies and report unresolved metadata. Sources: https://github.com/icsharpcode/ILSpy ; https://www.nuget.org/packages/ilspycmd ; https://learn.microsoft.com/dotnet/framework/tools/ildasm-exe-il-disassembler ; https://learn.microsoft.com/dotnet/core/deploying/native-aot/
