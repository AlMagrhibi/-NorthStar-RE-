# Native operational reference
Use tool catalog for Ghidra/JDK/DUMPBIN/PE-bear, inspect release documentation and matching JDK. Verify known native fixture import/headless, then import authorized static sample in isolated guest. Match loader, machine, compiler spec and image base to observed headers. Inspect imports, exports, entrypoints, cross references, calling conventions, data references and inferred structs. Validate decompiler output against instructions and addresses. Compare PE metadata with independent static tool. Preserve project logs and exact configuration. Never treat pseudocode as original source or run target. See headless-cheatsheet.md and installed analyzeHeadless README. Sources: https://github.com/NationalSecurityAgency/ghidra ; https://learn.microsoft.com/windows/win32/debug/pe-format
