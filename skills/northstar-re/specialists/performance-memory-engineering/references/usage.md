# Reproducible performance and memory profiling — reference and verification guide

Read exact installed-version docs before use. No automatic downloads or execution of untrusted code.

## Windows Performance Recorder (`wpr`)
- Official: https://learn.microsoft.com/windows-hardware/test/wpt/
- Usage: https://learn.microsoft.com/windows-hardware/test/wpt/windows-performance-recorder
- Local check: Record bounded local test workload; stop capture and review data sensitivity.

## Windows Performance Analyzer (`wpa`)
- Official: https://learn.microsoft.com/windows-hardware/test/wpt/
- Usage: https://learn.microsoft.com/windows-hardware/test/wpt/windows-performance-analyzer
- Local check: Open an ETL trace generated by a local benchmark; validate time units.

## AddressSanitizer (`asan`)
- Official: https://learn.microsoft.com/cpp/sanitizers/asan
- Usage: https://learn.microsoft.com/cpp/sanitizers/asan
- Local check: Compile a clean owned fixture with sanitizer enabled; check compiler and architecture support.

## .NET diagnostics (`dotnet-diagnostics`)
- Official: https://learn.microsoft.com/dotnet/core/diagnostics/
- Usage: https://learn.microsoft.com/dotnet/core/diagnostics/
- Local check: Collect counters only from owned local test process; avoid secrets and dumps by default.

## Process Explorer (`process-explorer`)
- Official: https://learn.microsoft.com/sysinternals/downloads/process-explorer
- Usage: https://learn.microsoft.com/sysinternals/downloads/process-explorer
- Local check: Observe own fixture process and expected modules.

## WinDbg (`windbg`)
- Official: https://learn.microsoft.com/windows-hardware/drivers/debugger/
- Usage: https://learn.microsoft.com/windows-hardware/drivers/debugger/
- Local check: Trusted dump or owned fixture; no unknown execution

## PIX on Windows (`pix`)
- Official: https://devblogs.microsoft.com/pix/
- Usage: https://learn.microsoft.com/windows/pix
- Local check: Confirm compatible GPU/API; capture owned Direct3D demo.

## Fixture and evidence
Repeatable owned benchmark and clean sanitizer fixture; no real credentials in traces.
Record expected versus observed results, exact tool version, exit status, source and output hashes.
