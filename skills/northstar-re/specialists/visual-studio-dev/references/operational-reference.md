# Visual Studio C++ / C# operational reference
Check .sln/.slnx, .vcxproj, .csproj, global.json, .vsconfig, SDK and architecture. Use vswhere and Developer PowerShell; confirm compiler, linker, MSBuild, SDK and targeting packs. For trusted C++ code inspect `cl /?`, `link /?`, `dumpbin /?`; build with discovered configuration and platform, CMake presets or MSBuild. For trusted .NET code use dotnet SDK matching global.json/TFM; inspect dependencies before approved restore, then build and test. Legacy .NET Framework uses required targeting packs and MSBuild. Verify exports, PDB match, exception settings, module architecture, ABI, packing, calling convention, ownership and UTF encoding. Use C ABI with explicit exports and C# SafeHandle/P/Invoke; test round trips and boundary errors. Debug only owned/trusted builds and authorized dumps; WinDbg offline, symbols only approved. Never build untrusted decompiled project directly. Record architecture, build logs, tests, failures and warnings.
