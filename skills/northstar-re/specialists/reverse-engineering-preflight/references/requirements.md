# Windows 11 tool requirements
Use environment-discovery-setup first. Windows 11 build 22000 or newer, native architecture identified, sufficient disk/RAM for selected workload. Verify Rust MSVC and Cargo, signed/provenance-checked tools and isolated analysis environment. For ILSpy read installed `--help`, release notes and NuGet package requirements; existing preflight's SDK 10 hint refers to its 11.x baseline only, not all versions. A verified installed CLI startup is stronger than an SDK assumption. If selecting a different release, use its actual requirements and report discrepancy. For Ghidra read its own application properties and release documentation, verify both java and javac of compatible JDK; no fixed JDK across releases. For Visual Studio discover installed instances, SDK, toolset and project compatibility. See environment specialist catalog and runbook for source links and evidence. Use `Get-FileHash -Algorithm SHA256` for artifacts. No Windows live validation is implied by synthetic tests. Historical Fedora references are not operational instructions.
