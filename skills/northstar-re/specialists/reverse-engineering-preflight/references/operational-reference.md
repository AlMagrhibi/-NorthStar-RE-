# Preflight reference
Use full environment inventory first. Hash with Get-FileHash, inspect local script output and route from headers, not extension. PE machine and CLR metadata distinguish native/managed/mixed; malformed/truncated files remain uncertain. High entropy is not encryption proof. Scope attestation is not independently verified authorization. Do not execute target, modify original or send sample over network. Record PASS/NEEDS_REVIEW/BLOCKED, tool readiness, hash and route. See requirements.md and install-windows.md. Source: https://learn.microsoft.com/windows/win32/debug/pe-format
