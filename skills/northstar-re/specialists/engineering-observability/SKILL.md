# Collect engineering evidence
Read master `../../SKILL.md`, `../../references/v7-engineering-workflow.md`, `../../references/v8-project-governance.md` and `references/usage.md`.

Record UTC, task, exit codes, durations, paths and artifact hashes in project-local redacted logs. Avoid logging credentials or uploading samples; distinguish measured from estimated.

Use approved tools and local trusted fixtures. Update Markdown and evidence before closure; no secret retention or unsupported completion claims.

## Mandatory V8 documentation
Follow `../../references/v8-project-governance.md` and `engineering-documentation`: record material actions, results, redacted evidence, decisions, blockers and handoff in project Markdown. Do not overwrite existing documentation or log secrets.
