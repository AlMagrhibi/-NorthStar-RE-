# NorthStar RE Framework V11 — مرشح الإصدار الأول

ماستر واحدة northstar-re، 52 تخصصًا داخليًا، 108 مدخلات أدوات ومراجع، محرك Rust 0.3.0، دون اعتماد تشغيل على Python.

يشمل هذا المرشح السورس والقفل والمهارات والبحث والتوثيق والمثبت وأدلة البناء والاختبارات والبصمات وSBOM. لا تنشر الحزمة التنفيذية إلا بعد نجاح بوابات CI الإلزامية واختبار EXE وdoctor ودورة المثبت على Windows.
