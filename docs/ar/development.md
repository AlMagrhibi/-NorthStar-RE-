[فهرس التوثيق](../README.md) · [English](../en/development.md)

## البناء والاعتماديات
ثبّت سلسلة Rust المحددة وMSVC وأدوات C++ على Windows. داخل skills/northstar-re/engine/nsre شغّل fmt ثم check ثم test ثم clippy ثم build --release، مع --locked في أوامر Cargo المناسبة. ملف Cargo.lock معتمد داخل المصدر؛ جيل V11 منفصل عن إصدار crate وهو 0.3.0. الاعتماديات المباشرة rayon وwalkdir وsha2 وserde_json وrusqlite مع SQLite مدمج. راجع اختلافات القفل والتنبيهات والتراخيص؛ لم يعتمد المالك ترخيصًا مفتوح المصدر للمنظومة.

## الاختبارات والقياس
تختبر Rust الجرد والتخزين المؤقت والمقارنة وعزل المشاريع ورفض القواعد الغريبة والبوابات ونقاط الاستعادة والمسارات. يستخدم Test-Installer.ps1 محرك Windows الحقيقي في مجلدات مستخدم مؤقتة معزولة. يتحقق Validate-Package.ps1 من الكتالوج والروابط والبصمات وبعض أنماط الأسرار. القياس بملفات اصطناعية فقط؛ قبول الأيجنت اختبار منفصل.

## التوسعة والأمان والنشر
أضف الوظائف بعقد CLI واضح وحدود موارد واختبارات حقيقية. أي تخصص جديد يحتاج name وdescription متطابقين وتحديث سجل التخصصات والأعداد عن قصد. لا يوجد SDK تنفيذي للإضافات أو ABI جاهز؛ تكامل الأيجنتات إرشادات تسجيل، وAPI المحلي للقراءة فقط. اتبع RELEASE.md وSECURITY.md، وامنع النشر عند فشل بوابات CI. لا ترفع حالة المشاريع أو عينات المستخدم أو المفاتيح أو سجلاته.
