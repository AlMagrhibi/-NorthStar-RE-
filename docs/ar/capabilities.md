# القدرات الهندسية

[فهرس التوثيق](../README.md) · [English](../en/capabilities.md)

## التحليل الثنائي والهندسة العكسية
ينفذ المحرك الجرد والتجزئة والفهرسة. يوفر probe وanalyze تلميحات التوقيع والإنتروبيا ورأس PE ضمن حدود قراءة محددة؛ لا يمثلان محلل PE/CLR كاملًا أو أداة فك تشفير أو استرجاع سورس. استخدم تخصصات Ghidra وأتمتة Java وILSpy والأدوات الأصلية الموثقة مع عينات اختبار مصرح بها، وحافظ على الملفات الأصلية.

## البيانات والتوازي
يعدد walkdir الملفات دون اتباع الروابط. يستخدم Rayon عدد عمال مضبوطًا من 1 إلى 64 ودفعات محدودة وكاتب SQLite واحدًا. يعيد النمط strict التجزئة، أما cache المعتمد على الحجم والتاريخ فاسترشادي. يصدر export سجلات JSONL وتتطلب المقارنة تشغيلين strict مكتملين لنفس المصدر.

## Windows وRust وC++ وC#
تغطي التعليمات MSVC وWindows SDK وABI وبناء Visual Studio والخوادم والأدوات المدارة. doctor يكتشف مرشحات PATH ولا يصادق على جاهزيتها. لا تُستبدل مكونات C++ وC# العاملة ولا يستخدم Python كبديل.

## الخوادم والقواعد والشبكات والأداء
توجه التخصصات هندسة الحسابات والألعاب والمخططات والترحيل وتشخيص الشبكات باستخدام هويات وعينات اصطناعية وخدمات محلية معزولة. لا تتضمن الحزمة خادم لعبة أو وصولًا لخدمات إنتاج. يقاس الأداء على بيانات قابلة لإعادة الإنشاء مع توثيق المضيف والإصدار وحالة التخزين المؤقت ودقة النتائج، دون أرقام سرعة افتراضية.
