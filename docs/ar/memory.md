## حالة المشروع
ينشئ init عشرين قالب توثيق وملفات حالة JSON دون استبدال الملفات الموجودة. تحفظ الجلسات والمعرفة والخطط المراجعة تراكميا داخل .northstar/state/framework.sqlite. جدول records يتضمن id وkind وpayload وcreated_ms؛ هوية التطبيق 1314083398 وإصدار المخطط 1. تعرض القراءة أحدث 100 سجل كحد أقصى؛ البحث نصي جزئي وليس استرجاعًا دلاليًا.

## فهرس الملفات والأدلة
تعرف schema.sql جداول runs وfiles وissues وهوية التطبيق 0x4e535245 وإصدار المخطط 1. يسجل strict تجزئة جديدة بينما إعادة استخدام بيانات الحجم والتاريخ استرشادية. الأدلة مسارات نسبية وبصمات متوقعة. تنسخ checkpoints قائمة ملفات مراجعة مع التحقق من البصمات ورفض المسارات الداخلية؛ لا تستعيد المشروع تلقائيا.

## الاستمرارية والترحيل
يعرض resume الحالة القديمة وسجل الجلسات الجديد. استخدم أحدث سجل مُراجع ووثّق الخطوة التالية والعوائق. لا يوجد ترحيل آلي للمعرفة القديمة. انسخ بيانات المشاريع احتياطيًا بشكل مستقل، ولا تدخل مجلدات .northstar في مستودع المنظومة أو إصداراتها.
