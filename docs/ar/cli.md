# مرجع CLI الكامل

[عقد الأوامر المعتمد](../../skills/northstar-re/references/v11-native-contract.md) يوضح كل الواجهات والمعاملات وحدودها. [قائمة الأوامر والمثال](../en/cli.md). استخدم المسار المطلق لـnsre.exe وسجل doctor أولًا. init وresume يحتاجان مشروعًا موجودًا ومصرحًا به؛ index يحتاج قاعدة خارج مصدر الملفات. مدخلات JSON تراجع وتنقح ثم تؤكد عبر --reviewed-redacted. jobs سجل خطط وليس موزع عمال، وdependency-audit مراجعة بيانات لا فحص ثغرات، وdoctor اكتشاف لا شهادة جاهزية أدوات.
