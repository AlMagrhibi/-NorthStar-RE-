# مختبر الأداء والتوسع

تختبر أداة Measure-Engine.ps1 سعات 1000 و10000 و100000 و1000000 ملف اصطناعي بمحتوى ثابت 64 بايت، وتتحقق من العدد وبصمة كل سجل مصدر. زمن إنشاء الملفات خارج زمن الفهرسة، ولا ترفع بيانات المستخدم أو اللعبة.

تسجل الزمن والملفات والثواني ومعدل البايتات وزمن CPU عند توفره وعينة الذاكرة القصوى وحجم القاعدة ونسبة إعادة الاستخدام ودقة النتائج. قياس الذاكرة بالعينة لا يضمن التقاط القمة الفعلية، وظروف cache والقرص غير مضبوطة. تعاد مقارنة strict وreuse-metadata دون اعتبار cache دليل سلامة. الاستعادة بعد الانقطاع حقل غير مقاس صراحة.

[لوحة القياسات الفعلية](../reports/PERFORMANCE-AR.md). لا تستنتج أداء Windows من Linux، ولا تستنتج سعة لم تختبر من أرقام أصغر. [المنهج الكامل](../en/performance.md).
