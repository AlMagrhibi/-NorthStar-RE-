# مسارات العمل وتعدد المشاريع

[فهرس التوثيق](../README.md) · [English](../en/workflows.md)

## مسار التحليل المصرح
1. حدد النطاق واكتشف البيئة وتحقق فعليًا من الأدوات اللازمة.
2. احفظ نسخة مصرحًا بها واحسب بصمات strict.
3. اختر التخصصات وفق أدلة الملف والخدمات.
4. حلل بأدوات أصلية محدودة، واستخدم Java مع Ghidra.
5. أكد النتائج وسجل البصمة والموقع والثقة والحدود.
6. حدّث التوثيق والمعرفة المنقحة وتسليم الجلسة وبوابات الجودة.

## تعدد المشاريع والاستعادة
محرك مركزي واحد يخدم مسارات مشاريع صريحة مستقلة، لكل منها توثيقه وقاعدته وأدلته ونقاطه. لا تخلط فهارس المصادر، واجعل ناتج المسح وقاعدة الفهرسة خارج المصدر. العزل تنظيم للمشاريع وليس حاجز أمان ضد عملية أخرى بنفس صلاحيات المستخدم. يحفظ jobs خطط DAG ولا ينفذ جدولة. بعد الانقطاع راجع الحالات الجزئية وأعد strict؛ لا يوجد استئناف دقيق. استعادة تثبيت المنظومة لا تمس بيانات المشاريع.
