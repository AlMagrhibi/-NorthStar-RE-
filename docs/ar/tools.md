تم التحقق من 108 مدخلات بين تطبيقات ومشروعات مصدر ومراجع، وليست برامج مرفقة أو مثبتة. [الكتالوج الكامل وروابطه الرسمية](../en/tools.md). يكتشف doctor ستة عشر مرشحًا فقط في PATH؛ يلزم فحص المصدر والترخيص والإصدار والتشغيل الفعلي قبل اعتماد أداة. أي مسار خارجي يتطلب Python غير مدعوم في المسار Native، ويستبدل بأداة أصلية موثقة أو Java عند ملاءمتها، وإلا تكون المهمة BLOCKED.
