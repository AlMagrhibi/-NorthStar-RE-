# بدء الاستخدام

[فهرس التوثيق](../README.md) · [English](../en/getting-started.md)

## مقدمة
تجمع المنظومة ماستر واحدة و52 تخصصًا إرشاديًا ومحرك Rust محليًا. جيل V11 يستخدم المحرك 0.3.0. وجود السورس لا يثبت تشغيل Windows أو تكامل الأيجنت.

## المتطلبات
Windows 11 x64 وأيجنت متوافق ومسار مهارات موثوق ومساحة كتابة داخل LOCALAPPDATA. الحزمة التنفيذية لا تحتاج Rust؛ البناء من السورس يحتاج Rust 1.91.1 وCargo وVisual Studio C++ Build Tools مع Windows SDK وMSVC x64. أدوات الإدارة تعمل عبر Windows PowerShell 5.1 أو PowerShell 7، دون Python أو صلاحيات إدارية.

## البداية والتشغيل الأول
اتبع [التثبيت](../../INSTALL.md)، وتحقق من مصدر الإصدار وبصمته، ثم فك الحزمة كاملة وأغلق الأيجنت وشغّل Install.cmd بالمسار الصحيح. شغّل Doctor.cmd، ثم اكتشف الماستر داخل الأيجنت. لا تفترض تطابق أوامر الاستدعاء: FreePi/Pi قد يدعمان /skill:northstar-re وCodex يستخدم $northstar-re وClaude يستخدم /northstar-re. استخدم المسار المطلق للمحرك المسجل في الماستر، ثم doctor وinit وresume داخل مشروع مصرح به.

## الإعداد وحل الأعطال
حدد -Agent أو -SkillRoot صراحة عند الالتباس. لا يعدّل المثبّت إعدادات الأيجنت الأخرى. إعداد المحرك عبر معاملات CLI؛ لا يوجد ملف إعداد عالمي مخفي. غياب Cargo أو MSVC يتطلب تثبيتًا صريحًا أو حزمة تنفيذية موثقة. تنزيل الاعتماديات يحتاج -AllowDependencyDownload. لا تتجاوز سياسة تنفيذ PowerShell. رفض الملكية يحمي الملفات الموجودة؛ راجع ترحيلها يدويًا. نتائج scan الجزئية تحتاج مراجعة الأخطاء والروابط المتخطاة.
