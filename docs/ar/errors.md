# الأخطاء والتشخيص

[فهرس التوثيق](../README.md) · [English](../en/errors.md)

| الواجهة | القيمة | المعنى |
|---|---|---|
| CLI | 0 | اكتمل الأمر؛ راجع المعنى الفعلي للمخرجات |
| CLI | 1 | مدخل غير صالح أو فشل تشغيل؛ راجع stderr |
| CLI | 2 | جرد جزئي أو بوابة جودة مرفوضة |
| API | -32700 | JSON غير صالح |
| API | -32600 | طلب غير صالح |
| API | -32601 | طريقة غير معروفة |
| API | -32602 | معاملات غير صالحة |
| API | -32000 | فشل التهيئة أو التشغيل أو ربط المشروع |

يسجل المثبت فشله في installation.jsonl ويعيد قيمة غير صفرية. لا يوجد كتالوج E-number ثابت. يحمي رفض الملكية المهارة الموجودة، وتحتفظ الترقية المرحلية بالنسخة السابقة وتستعيدها عند الاستثناء. انقطاع الطاقة أو العملية يحتاج مراجعة المجلدات المرحلية؛ إعادة تسمية المجلد واستبدال ملف التسجيل عمليتان ذريتان منفصلتان وليستا معاملة واحدة عبر الأقراص. لا تستخدم Runtime بديلًا لتجاوز الفشل، ونقّح التشخيص قبل مشاركته.
