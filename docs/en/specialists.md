### reverse-engineering-preflight

Mandatory read-only gate before any ILSpy/ilspycmd or Ghidra work on EXE, DLL, ELF, firmware or game-client binaries. Confirms authorization and scope, hashes and classifies the file from its headers, checks the toolchain against official requirements (the JDK Ghidra needs is read from the install itself, ilspycmd needs .NET SDK 10), produces a PASS / NEEDS_REVIEW / BLOCKED decision with JSON and PREFLIGHT.md reports, and routes to the right tool skill. Use whenever the user wants to decompile, disassemble or analyze a binary, asks if ILSpy or Ghidra is ready, or is about to install them, even if they never say "preflight".

[Source](../../skills/northstar-re/specialists/reverse-engineering-preflight/SKILL.md) · Status: instruction module; runtime integration UNVERIFIED.
