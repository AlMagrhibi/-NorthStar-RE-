# تثبيت وترقية NorthStar RE على Windows 11

المصدر المعتمد: https://github.com/AlMagrhibi/-NorthStar-RE- (مستودع خاص؛ استخدم حساب GitHub مصرحًا له). لا ترسل التوكن أو كلمة المرور للأيجنت أو في السجلات. استخدم Git Credential Manager أو `gh auth login` التفاعلي. يتطلب Git وPython 3.10+ للاختبارات. اكتشف مسار المهارات الفعلي من إعدادات الأيجنت وتوثيقه.

## التثبيت الأول

1. استنسخ المستودع في مجلد مستقل عن مجلد المهارات. تحقق من origin والـcommit ومحتويات المصدر والتراخيص. إذا لم يوجد `skills/northstar-re/SKILL.md` و`tests/`، توقف: النشر غير مكتمل.
2. بعد مراجعة الكود، نفّذ:

```powershell
git clone https://github.com/AlMagrhibi/-NorthStar-RE-.git NorthStar-RE-source
Set-Location NorthStar-RE-source
git rev-parse HEAD
py -3 -m unittest discover -s tests -v
```

3. اكتشف مسار المهارات المعتمد. انسخ مجلد `skills/northstar-re` بالكامل مع التخصصات والمراجع إلى staging مجاور لمسار التثبيت، ثم فعّله بعد التحقق. لا تستبدل نسخة قائمة دون مسار الترقية.
4. أعد تحميل المهارات إذا تطلب المضيف ذلك، واستدعِ `northstar-re` أو `/skill:northstar-re` إذا كانت الصيغة مدعومة. اختبر فحص البيئة وسجّل الـcommit والنتائج.

## الترقية

1. اكتشف النسخة المثبتة ومسارها والـcommit السابق من سجل التثبيت. اجلب المصدر إلى staging مستقل؛ لا تعمل git pull داخل مجلد مهارة نشطة.
2. تحقق من origin وHEAD. قارن الإصدارين عبر git diff واقرأ CHANGELOG وSKILL.md وأي تغييرات في السكريبتات. راجع التبعيات والصلاحيات الجديدة.
3. احتفظ بنسخة احتياطية كاملة من المهارة القديمة وتخصيصاتها. احمِ docs/ و.northstar/ الخاصة بالمشروعات، ولا ترفعها أو تحذفها أو تستبدلها. لا تدمج تعارضات التخصيص بصمت.
4. اختبر المصدر الجديد قبل التفعيل. تحقق من بصمات الملفات إذا توفرت. بعد الموافقة على التغييرات المؤثرة، بدّل المجلد من staging إلى مسار التثبيت بعملية rename على نفس وحدة التخزين مع معالجة الفشل. أوقف الجلسات النشطة إن لزم.
5. أعد تحميل الماستر واختبر استدعاءها وفحص البيئة. عند الفشل استعد النسخة السابقة. سجل القديم والجديد، نتائج الاختبارات، موضع النسخة الاحتياطية وأي عوائق في Markdown. إذا كان الـcommit نفسه ولا توجد فروق محلية، لا تستبدل النسخة.

## نص جاهز للأيجنت

> ثبّت أو رقِّ NorthStar RE من https://github.com/AlMagrhibi/-NorthStar-RE- . اقرأ README وdocs/INSTALL-UPGRADE.md وCHANGELOG. اكتشف بيئتك ومسار المهارات الفعلي، وتحقق من صلاحية الوصول واكتمال المصدر والـcommit. قارن النسخة المثبتة، وراجع التغييرات، وأنشئ نسخة احتياطية، واختبر النسخة الجديدة قبل تفعيلها. حافظ على ملفات المشاريع وذاكرتها وتخصيصاتها. لا تثبت أدوات إضافية أو تنفذ كودًا غير موثوق دون الموافقة اللازمة. استدعِ northstar-re واختبر التحميل، ثم قدم تقرير Markdown بالعربية عن النتائج وأي عوائق وموضع الاستعادة. لا تدّع نجاح الترقية إذا لم تنفذ فعليًا.

## الحدود

الترقية إجراء ينفذه الأيجنت المستضيف وليست خدمة تحديث ذاتية. نجاح اختبارات Python لا يعني نجاح تشغيل Visual Studio أو أدوات التحليل على Windows 11. الأدوات الخارجية ليست مرفقة. لا تنفذ الملفات غير الموثوقة، ولا تستخرج بيانات اعتماد أو تتجاوز أنظمة الحماية.
