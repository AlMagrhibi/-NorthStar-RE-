# Installation and upgrade

The current authoritative procedure is [INSTALL.md](../INSTALL.md) and the executable agent guide [INSTALL-FOR-AGENTS.md](../INSTALL-FOR-AGENTS.md). Read the [compatibility matrix](en/compatibility.md) before choosing a path or invocation syntax.

The central manager preserves project data, refuses unowned skill directories, installs a verified engine and registers one master with internal specialist guides. Update is explicit; use authenticated release acquisition, hashes and a reviewed compatible manifest, then run Update.cmd from the extracted package. Rollback uses an owned central backup. No Python, silent prerequisites, policy bypass or administrator elevation is used.

تعليمات التثبيت والترقية المعتمدة في الروابط أعلاه. راجع التقارير الحالية قبل اعتماد Windows أو أي تكامل؛ ملفات الحالة القديمة أرشيف لحزمة الإدخال فقط.
