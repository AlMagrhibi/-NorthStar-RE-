# تقرير الأمان والتراخيص

- فحص CRC وبصمات ملفات الإدخال: PASS.
- لا ملفات Python أو ملفات اعتماديات حسابات أو عينات مشاريع في الحزمة الأصلية حسب الجرد والمراجعة.
- فحص أنماط أسرار مختارة في Validate-Package.ps1، مع منع نشر .northstar وقواعد المشاريع ومخرجات target.
- اختبارات مسارات وملكية وقواعد غريبة وأدلة وcheckpoint أضيفت ونجحت على Linux؛ دورة المثبت تحتاج سجل Windows مستقلًا.
- فحص تصريحات تراخيص 59 اعتمادًا من cargo metadata: PASS بعد مراجعة التعبيرات. رخصة r-efi ذات خيارات MIT/Apache/LGPL سمح بها بمسار MIT أو Apache، وليس بفرض LGPL؛ تعبير Unicode-3.0 التزام إشعار مستقل. لا يعد الفحص مراجعة قانونية أو بديلًا لنسخ إشعارات upstream.
- تم إنشاء CycloneDX SBOM محلي يحصر المكونات وعلاقاتها. CI يولد ملفه من نفس Cargo.lock.
- cargo-audit 0.21.2 تعذر عليه قراءة CVSS 4.0 في قاعدة RustSec الحديثة؛ رُفع إلى 0.23.0 بدل تجاهل الخطأ أو تثبيت قاعدة تنبيهات قديمة. النتيجة النهائية PENDING حتى اكتمال الفحص الجديد.
- لا شهادة أمان ولا ادعاء تغطية كاملة للأسرار. فحوص المسارات لا تعالج كل سباقات النظام أو hardlinks؛ استخدم مسارات مستقرة موثوقة وعزلًا مناسبًا.
- لا تغيير لخصوصية المستودع ولا صلاحيات أطراف أخرى ولا ترخيص مفتوح المصدر جديد. الترخيص النهائي للمنظومة قرار المالك.
