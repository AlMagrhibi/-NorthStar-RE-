# Framework knowledge versus project knowledge

Framework research remains in [docs/V10-RESEARCH-AR.md](../docs/V10-RESEARCH-AR.md), the master references and specialist operational guides. The [complete tool catalog](../docs/en/tools.md) preserves upstream provenance links.

Private project knowledge belongs only in that project's .northstar state, reviewed and redacted. Do not copy binaries, game data, keys, account records, target findings, project SQLite databases or engineering outputs into this directory. No automatic research download service or vector database is implemented.
