# Support

Use private repository issues for reproducible framework problems. Include framework/engine version, OS, agent version, exact redacted command, expected/observed behavior and relevant exit code. Never upload game clients, private binaries, project DBs, .northstar data, credentials or raw install logs. Security reports follow SECURITY.md. Support is best-effort; no release-readiness or response-time guarantee is implied.

## الدعم بالعربية
افتح Issue داخل المستودع الخاص مع الإصدار والنظام والأيجنت والأمر المنقح والنتيجة المتوقعة والفعلية. لا ترفع ملفات المشاريع أو المفاتيح أو السجلات الخاصة. لا يوجد ضمان زمني للدعم أو ادعاء جاهزية غير مثبت.
