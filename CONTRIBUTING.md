# Contributing
1. Confirm scope and authorization. Create a task and acceptance criteria.
2. Add or update specialist references with upstream sources and limitations. Do not duplicate catalog IDs.
3. Update tests, README and CHANGELOG. Run `python -m unittest discover -s tests -v`.
4. Review diff, secrets and licenses; retain unrelated user changes. Document test evidence and outstanding Windows acceptance.
5. Submit a scoped PR; no release claim without actual evidence. No repository-wide license has been assigned; obtain owner approval before redistribution.
