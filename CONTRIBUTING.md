# Contributing

Keep contributions within owner-approved scope and private visibility. Read AGENTS.md and the developer guide. Preserve all native capabilities and specialist research. New code uses Rust; Windows management/tests use PowerShell; Ghidra automation uses Java when needed. Python runtime/fallback/tests are forbidden. Run mandatory CI checks, update contracts/docs/registry and include reproducible evidence. Do not introduce an open-source framework license, third-party rights grant, private targets or credentials.

## المساهمة
حافظ على خصوصية المستودع وهوية الماستر وقدراته. أرفق أدلة واختبارات قابلة لإعادة التنفيذ، وحدث التوثيق والكتالوج. لا تدخل Python أو ترخيصًا جديدًا أو بيانات خاصة دون اعتماد المالك.
